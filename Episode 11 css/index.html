1.Inline CSS

Inline CSS is used to apply a unique style to a single HTML element.

  • Location: Inside the HTML tag using the style attribute
  • Best For: Quick fixes, testing, or overriding other styles.
  • Specificity: highest: it overrides both intrnal and external CSS.
  • Drawback: Hard to maintain and makes HTML code clutred.
Example: h style="color: blue; font-size: 20px;">Hello World.h1.

Internal CSS

Internal CSS(Embedded CSS) is used to define style for a single HTML page.

  • Location: within a style tag, typically placed in the head section of the HTML Document.
  • Best For: Single-page website or unique page layouts.
  • Specificity: Medium; it overrride external CSS but is overriden bt inline CSS.
  • DearBAck: Increase the size of the HTML file, which can slow down page loading.

External CSS

External CSS is the standard method for professional web development. It allows you to stlye multiple pages at once.

  • Location: A separate file with a .css extension, linked to the HTML via the link tag in the head
  • Best For: Multi-page websites and maintaning a consistent design.
  • Specificity: Lowest; it is easily overridden by internal or inline styles.
  • Advantage: Keeps code clean (separation of concern), reduces file size, and allowa for browser coaching.
